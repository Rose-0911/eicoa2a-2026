Functions package reusable blocks of code to perform specific tasks. They break complex problems into manageable pieces, reduce duplication, and make code cleaner and easier to maintain.
Parameters act as inputs passed into a function so it can operate on dynamic data. A return value is the output the function sends back to the caller once execution finishes, allowing the result to be used elsewhere in the program.
Docstrings explain what a function, class, or module does, detailing its parameters, return types, and expected behavior. They serve as built-in documentation, helping developers understand code quickly without reading through the implementation line by line.
Local variables are defined inside a function and accessible only within its scope, existing briefly while the function runs. Global variables are declared outside functions and remain accessible throughout the entire program's lifecycle.
Git is a version control system that tracks code changes over time. It allows developers to create branches to experiment safely, revert to previous versions if bugs occur, and collaborate seamlessly across teams without overwriting each other's work.
